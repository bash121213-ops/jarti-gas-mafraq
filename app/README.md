# تطبيق جَرّتي (Flutter)

تطبيق أندرويد وiOS لتوصيل أسطوانات الغاز في المفرق.

```bash
flutter pub get
flutter run
flutter test
flutter build apk --release
```

- رمز التحقق التجريبي: `123456`
- الأسعار: 7.00 د.أ للأسطوانة + 0.10 د.أ توصيل لكل طلب.
- الأسرار لا تُحفظ في الكود؛ استخدم `--dart-define=SUPABASE_URL=... --dart-define=SUPABASE_ANON_KEY=...`.

التفاصيل الكاملة في README المستودع.
