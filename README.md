# جَرّتي — تصميم واجهات تطبيق أسطوانات الغاز في المفرق

نموذج تصميم (Mockup) عربي باتجاه RTL لتطبيق توصيل أسطوانات الغاز في مدينة المفرق، مبني بـ HTML و CSS فقط وبدون أي مكتبات خارجية.

## الشاشات

- تسجيل الدخول برقم الهاتف
- الصفحة الرئيسية والطلب (أسطوانة حديد أو بلاستيك)
- تتبّع الطلب المباشر مع حالة الموزّع
- لوحة الموزّع / صاحب الديانة (الطلبات اليومية والسجل)

## الأسعار

- أسطوانة: ٧٫٠٠ د.أ (حديد أو بلاستيك)
- أجرة التوصيل: ٠٫١٠ د.أ فقط
- المجموع: ٧٫١٠ د.أ

## التشغيل

افتح `index.html` في المتصفح مباشرة، أو شغّل سيرفر محلي:

```bash
python3 -m http.server 3000
```

## الملفات

- `index.html` — الصفحة الكاملة بالشاشات الأربع
- `styles.css` — كل التنسيقات
- `img/` — صور التوصيل والمستودع وحي المفرق
